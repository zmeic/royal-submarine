# 皇家潜艇 🛟🐟

一个可以直接在浏览器里玩的**儿童海底探险小游戏**（V1.3 图鉴与成就版）。

🎮 **在线试玩：<https://zmeic.github.io/royal-submarine/>**

玩家登上「皇家潜艇」，抽一个身份，取个名字，然后开着潜艇去海底**捕鱼、寻宝、救助海洋动物**，
用赚到的积分去潜艇便利店换装备，再继续出发探险 —— 可以一直循环玩下去。
捕到的鱼和救助过的动物会记进**图鉴**，一路上还会解锁**成就徽章**。

- 纯 **HTML + CSS + 原生 JavaScript**，没有框架、没有后端、没有构建步骤
- **不依赖任何外部图片和音频**：美术是内联 SVG + CSS，音效是 Web Audio 现场合成
- 进度保存在浏览器 **localStorage**，刷新不会清零（升级到 V1.3 不会丢掉老存档）
- 桌面 / 平板 / 手机（竖屏与横屏）都能玩，支持触摸操作

## 一、怎么启动（两种方式，任选一种）

### 方式 1：直接双击打开（最简单）

下载/克隆本仓库后，直接双击 `index.html`，用浏览器（Chrome / Edge / Safari / Firefox）打开即可开玩。
项目故意没有使用 ES module，所以 `file://` 方式也能正常运行。

### 方式 2：起一个本地小服务器（推荐，更接近正式环境）

在项目根目录执行任意一条：

```bash
python3 -m http.server 8000
# 或者
npx serve .
```

然后浏览器打开 <http://localhost:8000> 。

> 建议在电脑上用普通窗口全屏玩；页面在 720px 以下的窄屏也能自适应。

## 二、怎么玩（核心闭环）

```
开始游戏 → 抽取身份 → 给角色起名字 → 进入皇家潜艇
   → 选择任务 → 完成小游戏 → 获得积分 + 收进图鉴 / 解锁徽章
   → 进入便利店 → 兑换装备 → 返回继续任务（循环）
```

### 身份（随机抽取，可以再抽）

| 身份 | 职责 | 专属加成 |
| --- | --- | --- |
| 船长 | 驾驶潜艇、查看距离、选择任务地点 | 能看到任务的**准确距离**，完成任务 **+1 分** |
| 潜水员 | 下潜、捕鱼、寻宝、救助海洋动物 | 捕鱼**时间 +5 秒**，寻宝**多挖 1 次** |
| 船员 | 做饭、照顾海洋动物、管理粮食 | 装备**损坏概率减半**，吃粮食**加成翻倍** |

### 三种任务

| 任务 | 玩法 | 得分 |
| --- | --- | --- |
| 捕鱼 | 鱼从两侧游过来，点中就捕到（限时 30 秒，至少捕到 1 条算完成） | 普通鱼 +2，稀有鱼 +5，皇冠鱼 +8 |
| 寻宝 | 6 片海底区域，挖错会提示「很近 / 有点远 / 很远」 | 找到宝藏 +6 |
| 海洋救援 | 三步：① 轻轻靠近动物 ② 选对工具 ③ 在绿色区域按下完成 | 成功救助 +10 |

任务没完成**不加分，也不扣分**。

### 声音

右上角有 **🔊 声音开 / 🔇 声音关**，默认开启、音量很轻，设置会被记住。
所有音效都是 Web Audio API 现场合成的，没有音频文件，不会拖慢加载。

有音效的地方：按钮点击、捕到鱼、捕到稀有鱼、找到宝藏、救援成功、
买到装备、抽签转动与定格、拿到新徽章、装备损坏、任务没成功（柔和的两声，不会吓到孩子）。

### 图鉴与成就 📖

右上角的 **📖 图鉴**（潜艇主界面和观景区也有入口）会打开一本册子，分三页：

| 分页 | 内容 | 怎么收集 |
| --- | --- | --- |
| 🐟 鱼类 | 9 种鱼，每种有名字、介绍和捕到过多少条 | 在捕鱼任务里捕到一次就永久收录 |
| 🐢 海洋朋友 | 3 种海洋动物 | 救援任务成功一次就收录 |
| 🏅 成就 | 14 枚徽章 | 达成条件自动解锁，灰色的下面写着还差多少 |

没收集到的条目是灰色剪影加一个问号，**不会**告诉孩子答案，留着让他自己去凑齐。

**九种鱼**（稀有鱼出现得少，鱼枪能提高稀有鱼的概率）：

| 普通鱼（+2） | 稀有鱼 |
| --- | --- |
| 蓝点鱼 · 小丑鱼 · 海草鱼 · 珊瑚鱼 · 小河豚 · 夜光鱼 | 黄金鱼 +5 · 彩虹鱼 +5 · **皇冠鱼 +8**（最难遇到） |

**十四枚徽章**：第一条鱼 / 小渔夫 / 捕鱼高手 / 大丰收 / 闪闪发光 / 皇冠加冕 /
鱼类图鉴大师 / 开箱时刻 / 寻宝猎人 / 海洋朋友 / 海洋守护者 / 出勤十次 /
积分小富翁 / 全副武装。

拿到新徽章时屏幕上方会弹出一张金色卡片，配一段小号音效，三秒后自己收起来，
不用点任何按钮、也不会打断正在玩的东西。

### 便利店

| 商品 | 价格 | 作用 |
| --- | --- | --- |
| 潜水衣 | 10 分 | 寻宝多挖 1 次；救援第 3 步判定更宽松 |
| 鱼钩 | 9 分 | 捕鱼时鱼更多、点击范围更大（**会损坏**） |
| 鱼枪 | 20 分 | 稀有鱼出现概率提高（**会损坏**） |
| 氧气瓶 | 4 分 | 捕鱼时间 +5 秒 |
| 粮食 | 2 分 | 去餐厅吃掉，下一个完成的任务额外加分 |

积分不足时购买按钮变灰，并直接告诉孩子「还差几分」。

### 装备损坏

鱼钩和鱼枪在**使用到它们的任务**结束时，有 **12%** 概率损坏（船员身份 6%）。
损坏后从装备列表移除，需要回便利店重新兑换。**不扣分**，只提示一句「用旧了，回便利店再换一个吧」。

### 潜艇（可点击的 2D 平面图）

六个房间都可以点击，每个都有画面和反馈：

- **驾驶区**：雷达 + 方向舵，任务距离表，任务入口
- **观景区**：三个方形大窗户，窗外有小鱼、稀有鱼、小海龟游过
- **餐厅**：餐桌 + 桌上的食物，可以「吃一份粮食」
- **储藏区**：装备清单 + 便利店入口
- **厕所**：洗手会冒一串小泡泡
- **舞台**：灯光摇摆，可以让船员「唱歌 / 跳舞」

### 存档与重新开始

保存内容：玩家姓名、身份、当前积分、当前装备、已完成任务数量、粮食加成，
以及**图鉴进度**（每种鱼捕到几条、每种动物救过几次、挖到几次宝藏、拿到哪些徽章）。
刷新页面后不会清零，回到首页可以点「继续上次探险」。
右上角「重新开始」会弹出**二次确认**，确认后才清空。

## 三、版本记录

### V1.3 —— 图鉴与成就（本次）

这一版给游戏加了**长期目标**：以前做完任务只剩一个分数，现在会留下痕迹。
**玩法、数值、积分、商店、装备、存档全部向下兼容，老存档不会清空。**

- **鱼分成 9 个种类**：蓝点鱼、小丑鱼、海草鱼、珊瑚鱼、小河豚、夜光鱼，
  以及三种稀有鱼（黄金鱼、彩虹鱼、皇冠鱼）。每种配色和花纹都不一样，
  捕鱼任务里游过去的鱼从此不再长得都一样
  - 皇冠鱼是这一版唯一的新数值：很难遇到，捕到 **+8 分**
  - 结算界面按种类报账（「小丑鱼 ×2 · 4 分」），跟图鉴里的名字对得上
- **图鉴**（📖）：鱼类 / 海洋朋友 / 成就 三个分页，没收集到的是灰色剪影加问号
- **14 枚成就徽章**：从"第一条鱼"到"鱼类图鉴大师"，达成时弹一张金色卡片
  + 一段小号音效，三秒后自己收起来，不打断正在玩的东西
- 入口：顶部信息栏、潜艇主界面、结算界面、观景区，四个地方都能打开图鉴
- 观景区顺便显示「已收录 X / 9 种鱼」
- 存档结构是**往上加**的，V1.2 以前的老存档读进来只是图鉴为空，
  积分和装备一个都不会丢；进游戏时会按已有进度**补发**够格的徽章（不弹卡片）

### V1.2 —— 按孩子的原画升级主界面视觉

- 参照孩子的原画重画潜艇：顶部皇冠、暖黄艇身、手绘描边、上下两层分区
- 新增休息区和设备区，八个房间都可点击
- 配色整体转暖（纸感面板、暖棕文字），海底加了海豚、水母、章鱼、海草
- 孩子的原画存进 `assets/sub-map.webp` 作为美术参考

### V1.1 —— 试玩优化

在第一版"能玩"的基础上，这一版重点是"**更像一个给孩子玩的游戏**"：

**试玩体验**
- 完成任务有 `+2 / +5 / +6 / +10` 的大号飘字、星星迸发和彩色纸屑
- 抽身份改成会减速的老虎机式抽签，定格时有光效和音效
- 捕到稀有鱼时整个水槽会闪光，配一串上行琶音
- 找到宝藏有开箱动画；救助成功后动物会恢复、转圈、游走
- 失败文案全部改得温和（"鱼儿今天游得快"而不是"你失败了"）
- 装备损坏改成有趣的随机说法（"被一条大鱼拽弯啦"）
- 文字整体变短，重要信息改用卡片、图标和小标签表达

**潜艇主界面**
- 每个房间里画上了家具：雷达会转、方向舵会摆、餐桌冒热气、
  舞台灯光摇摆、观景窗里有鱼游过、厕所冒泡泡
- 房间名牌移到顶部，不再压住家具
- 房间会轮流轻微闪一下，提示"这里能点"；鼠标悬停有反馈；点击有进入动画
- 艇身轮廓加粗、加了探照灯光束和转动的螺旋桨，方形窗户保留

**小游戏**
- 捕鱼：鱼的大小、速度、摆动幅度都有随机差异，游起来更自然；
  保证整条鱼都在水槽内（不会出现点不到的鱼）；速度调慢到适合儿童
- 寻宝：六片区域各有不同的海底装饰；挖错的提示加了**方向箭头**和冷热图标
- 救援：加了 1-2-3 步骤指示条和"现在要做什么"的明确提示；
  **选错工具不再直接结束**，可以一直重选；最后一步给 3 次机会

**代码结构（为正式美术做准备）**
- 新增 `js/art.js`：潜艇地图、房间场景等画面全部从业务逻辑里抽出来
- 新增 `js/sound.js`：音效系统
- 所有图都可以用一行配置换成图片，详见 `assets/README.md`

## 四、项目结构

```
index.html            所有界面（屏幕）的 HTML 结构
css/
  base.css            颜色变量、排版、海洋背景、气泡、飘字与星星特效
  components.css      按钮、面板、顶部信息栏、提示条、弹窗、身份卡、步骤条
  screens.css         各屏幕布局 + 手机/平板适配
  submarine.css       潜艇平面图 + 六个房间的小场景动画
  tasks.css           三个小游戏的样式
  collection.css      图鉴界面 + 新徽章弹卡
js/
  config.js           ★ 所有数值配置：身份、商品价格、损坏概率、任务参数、
                        房间、★鱼的种类（species）、★成就（achievements）
  art.js              ★ 美术资源层：潜艇地图、房间场景、图片替换表
  icons.js            ★ 全部占位美术（内联 SVG），可一键换成图片
  sound.js            音效系统（Web Audio 合成，无音频文件）
  storage.js          localStorage 读写（不可用时自动降级）
  state.js            游戏状态 + 存档（姓名/身份/积分/装备/任务数/图鉴收集）
  ui.js               屏幕切换、信息栏、提示条、加分飘字、星星迸发、确认弹窗
  submarine.js        潜艇平面图渲染 + 房间互动
  achievements.js     成就判断与新徽章弹卡
  collection.js       图鉴界面 + 鱼种类抽取
  shop.js             便利店
  tasks/
    fishing.js        捕鱼小游戏
    treasure.js       寻宝小游戏
    rescue.js         海洋救援小游戏（三步）
    index.js          任务选择、启动小游戏、积分结算（含身份奖励与装备损坏）
  main.js             启动与主流程（抽身份 → 起名 → 进艇 → 循环）
assets/
  favicon.svg         标签页图标
  sub-map.webp        孩子画的潜艇原画（美术参考）
  README.md           以后接入正式美术的说明
```

脚本按顺序用普通 `<script>` 标签加载，共享一个全局命名空间 `RS`（`RS.config` / `RS.state` / `RS.ui` / …）。

### 想改点什么？

| 想做的事 | 改哪里 |
| --- | --- |
| 调分数、价格、损坏概率、任务时间/次数 | `js/config.js` |
| **把占位图换成孩子画的图** | `js/art.js` 的 `RS.art.images`（详见 `assets/README.md`） |
| 改潜艇地图的房间位置 | `js/art.js` 的 `ROOMS` |
| 改音效 | `js/sound.js` 的 `RECIPES` |
| 加一个新任务 | 在 `js/tasks/` 加一个模块，注册到 `RS.taskGames`，再在 `js/config.js` 的 `tasks` 里加配置，并把 id 放进 `js/tasks/index.js` 的 `ORDER` |
| 加一个新房间 | 在 `js/config.js` 的 `rooms` 加一项，在 `js/submarine.js` 的 `ROOM_BOX` 给它一个位置，再写一个 body 函数 |
| 加一件新装备 | 在 `js/config.js` 的 `shopItems` 加一项（`breakable: true` 就会参与损坏机制） |
| **加一种新的鱼** | 在 `js/config.js` 的 `species` 加一项（颜色 + `weight` 出现概率即可，图鉴会自动多一格） |
| **加一个新成就** | 在 `js/config.js` 的 `achievements` 加一项，`type` 选一个已有的统计值、`need` 写数量 |
| 加一种全新的统计值 | 在 `js/state.js` 的 `stats()` 里多返回一个字段，成就的 `type` 就能用了 |

## 六、浏览器要求

现代浏览器即可（Chrome / Edge / Firefox / Safari 最近两年的版本）。
如果浏览器禁用了 localStorage（例如某些隐私模式），游戏照样能玩，只是刷新后进度不保留，首页会给出提示。
音效需要浏览器支持 Web Audio API；不支持时会自动跳过，不影响游戏。
