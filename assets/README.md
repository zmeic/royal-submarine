# assets/ — 美术素材目录

**这个目录就是以后放孩子画的图的地方。**

到 V1.3 为止，游戏里的画面仍然全是代码画出来的（内联 SVG + CSS），
这里放着 `favicon.svg`（浏览器标签页图标）和 `sub-map.webp`（**孩子画的潜艇原画**，
V1.2 的主界面就是照着它重画的，留作美术参考）。

---

## 一、换图只要改一个地方

所有可替换的图，都在 **`js/art.js`** 最上面的 `RS.art.images` 里登记。

```js
var images = {
  // fish: 'assets/fish-normal.png',     ← 把这一行前面的 // 去掉就生效
};
```

把图片文件放进 `assets/`，然后在这里写上 `id: '路径'`，
游戏里**所有**用到这个 id 的地方（任务、商店、潜艇地图、顶部信息栏……）
都会自动换成你的图片，其它代码一行都不用改。

举例：孩子画好了普通鱼和稀有鱼

```js
var images = {
  fish:     'assets/fish-normal.png',
  rareFish: 'assets/fish-rare.png',
};
```

保存、刷新浏览器，捕鱼任务里游过去的就是孩子画的鱼了。

### 图鉴里的九种鱼（可选，换不换都行）

V1.3 起捕鱼任务里的鱼分成九个种类。游戏默认用同一个鱼形状换配色画出来，
但每一种都可以单独换成孩子画的图，id 是 `fish-` 加上种类 id：

| id | 鱼 | id | 鱼 |
| --- | --- | --- | --- |
| `fish-blue` | 蓝点鱼 | `fish-night` | 夜光鱼 |
| `fish-clown` | 小丑鱼 | `fish-gold` | 黄金鱼（稀有） |
| `fish-grass` | 海草鱼 | `fish-rainbow` | 彩虹鱼（稀有） |
| `fish-coral` | 珊瑚鱼 | `fish-crownfish` | 皇冠鱼（稀有，头上有小皇冠） |
| `fish-puffer` | 小河豚 | | |

```js
var images = {
  'fish-clown': 'assets/fish-clown.png',   // 只换小丑鱼，其它八种还是用代码画的
};
```

换了图之后，捕鱼任务里游过去的鱼和图鉴里的那一格都会跟着变。
**只想改颜色不想画图**的话更简单：在 `js/config.js` 的 `species` 里改
`body` / `fin` / `belly` / `mark` 四个颜色就行。想加第十种鱼，
也是在同一个地方照着抄一行 —— 图鉴会自动多出一格，成就里「鱼类图鉴大师」
的数量记得同步改一下（`js/config.js` 的 `achievements` 里 `fishAll` 的 `need`）。

## 三、给孩子的画做成素材：实用建议

1. **格式**：`.png` 最省事（支持透明背景）。`.svg` 最清晰，但需要矢量软件。
   手机拍的照片也行，但记得先抠掉背景。
2. **背景要透明**：鱼、宝箱、动物这些"贴在画面上"的东西，
   背景必须是透明的，否则会出现一个白方块。
   （手机 App：medibang、稿定抠图；电脑：Photopea 免费网页版）
3. **画面朝向**：鱼默认**头朝右**。游戏会自动左右翻转，不用画两张。
4. **大小**：按上表的建议尺寸就好，大一点没关系（浏览器会缩放），
   但单张最好别超过 300KB，不然手机上加载会慢。
5. **命名**：用英文小写 + 连字符，例如 `fish-normal.png`、`captain.png`，
   不要用中文文件名（有些服务器会出问题）。

## 四、整张潜艇地图换成孩子的原画

这是最有成就感的一步。把孩子画的潜艇剖面图扫描 / 拍照后：

```js
var images = {
  subMap: 'assets/sub-map.png',
};
```

换上之后，地图会整张显示成那幅画。**但是六个房间的点击热区需要重新对位** ——
热区坐标在 `js/art.js` 的 `ROOMS` 里：

```js
var ROOMS = {
  bridge:  { x: 108, y: 118, w: 176, h: 214, ... },   // 驾驶区的位置和大小
  ...
};
```

把每个房间在画里的位置量出来填进去就行（坐标系是 960×470）。
这一步可以直接把画发给我，我来对位。

## 五、换完之后要检查什么

1. 刷新页面，看图有没有出来（没出来先看文件名大小写对不对）
2. 打开浏览器控制台（F12），看有没有 404 报错
3. 在手机上也打开看一眼，确认图片不会太大导致卡顿
4. 确认背景透明的地方没有出现白框
